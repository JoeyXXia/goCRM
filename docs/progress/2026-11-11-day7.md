## 复现与边界

沿用 [Day 6 报告](2026-11-10-day6.md) 的 Go 和浏览器命令。Go 测试使用专用测试库。旧本地账号首次复跑缺少更新以及 Casbin 表结构和索引权限，补齐专用库的 `UPDATE`、`ALTER`、`INDEX` 后通过。浏览器使用模拟 API 控制请求时序，真实数据库与签名 JWT 由 Go 测试覆盖。

最值得复查的边界是 A 的有效角色配合 B 的租户选择或部门 ID，以及租户切换时迟到的 A 响应。发布检查应以候选提交的两条 GitHub Actions 工作流结果为准。
